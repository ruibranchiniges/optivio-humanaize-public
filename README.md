# Humanaize — Sites institucionais públicos

Repositório de **publicação estática** dos materiais institucionais do Humanaize.

## Rotas

- `/ges/` — comunicação interna de adesão para líderes e áreas do Grupo Eletrônica Santana (GES).
- `/schuetz-vasitex/` — proposta institucional da Optivio para SCHÜTZ VASITEX.

A versão de trabalho e a governança de conteúdo permanecem no repositório privado correspondente. Este repositório contém exclusivamente os arquivos necessários para disponibilização pública via GitHub Pages.

## Publicação

A publicação é configurada no GitHub Pages a partir da branch `main`, diretório raiz (`/`).
